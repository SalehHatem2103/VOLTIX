# VOLTIX Data Analysis Training Portfolio

Hands-on projects completed during the **Data Analysis** training program at **VOLTIX**. A new task was delivered every three days, for **12 tasks** in total, each taking a real dataset from raw data to a final dashboard or report.

## Tools

| Tool | Used for |
|------|----------|
| **Python** (Pandas, Plotly Dash) | Data cleaning, analysis, interactive dashboards |
| **Power BI** | Interactive dashboards, KPIs, slicers, data storytelling |
| **Excel** | Pivot tables, data cleaning, dashboards, reporting |

## Top Projects

| Project | Tools | Scale | Highlights |
|---------|-------|-------|------------|
| [**Task 12: NYC Airbnb Market Analysis**](./task12(last)) (final project) | Power BI | 48,631 listings after cleaning | Pricing by borough (Manhattan $149 vs Bronx $65 median per night), room-type and price-band breakdown, host-type analysis (11.5% professional hosts), estimated revenue, and an interactive listing map. |
| [**Task 8: Medical Appointments No-Show Analysis**](./task8) | Excel | 102,846 appointments | No-show rate of 20.47%. Rate climbs from 4.5% for same-day bookings to 33% for bookings made 30+ days ahead. Breakdowns by neighbourhood and age group. |
| [**Task 11: Video Game Industry Analysis**](./task11) | Python + Power BI | 17,401 cleaned records | 12 analysis charts in Python plus a two-page Power BI dashboard: sales by genre, platform, publisher, region, and review scores over time. |
| [**Task 10: Movie Industry Analytics**](./task10) | Power BI | ~4,800 movies | 6 KPI cards (revenue, profit, ROI, rating, runtime), revenue and rating trends, top 10 movies, and profitability by runtime group. |
| [**Task 7: Hospital Analytics**](./task7) | Power Query + Power BI | 247 patient records | Cleaned reversed admission and discharge dates (29 records), built KPIs such as $618,995 total billing and 6.26 days average stay, with 4 interactive slicers. |

## Workflow Followed in Each Task

1. Understand the dataset and the business question
2. Clean the data (duplicates, missing values, invalid entries)
3. Explore and analyze (EDA)
4. Visualize and build an interactive dashboard
5. Summarize insights and recommendations
